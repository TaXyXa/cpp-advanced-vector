Улучшенный контейнер вектор

Собственная реализация шаблонного контейнера для хранения последовательных значений. Реализованы функции для заполнения и изменения данных (Emplace, Erase и др.), поддерживается работа с итераторами. Для оптимизации работы использована move-семантика. Работа с памятью автоматизирована и не требует внимания.

Для использования достаточно подключить .h файл к своему проекту.
